# Политика конфиденциальности NavXS

Последнее обновление: 14 сентября 2026 г.

## 1. Общие сведения

NavXS — это Android-приложение, которое может отображать навигационный оверлей с фиксированными кнопками для выбранных приложений.

Разработчик этого приложения собирает, хранит или обрабатывает персональные данные только в той мере, которая технически необходима для работы приложения.

## 2. Локальная обработка на устройстве

NavXS, как правило, обрабатывает информацию локально на устройстве.

Это включает в частности:

- имя пакета приложения, в данный момент находящегося на переднем плане
- выбор приложений, для которых должен быть включён оверлей
- настройки оверлея, заданные пользователем, такие как позиции, цвета, размеры, прозрачность и темы
- статус активации службы специальных возможностей
- URI изображения, которое пользователь при желании выбирает в качестве фона редактора позиционирования, вместе с заданной для него непрозрачностью

## 3. Цель обработки

Эта информация обрабатывается исключительно для того, чтобы:

- определить, нужно ли показывать оверлей для текущего открытого приложения
- показывать или скрывать оверлей
- выполнять настроенные навигационные действия
- сохранять и восстанавливать выбранные пользователем настройки локально

## 4. Служба специальных возможностей

NavXS использует API службы специальных возможностей Android (AccessibilityService). NavXS не является инструментом специальных возможностей для людей с ограниченными возможностями; служба необходима для основной функции приложения — навигационного оверлея.

### 4.1 Согласие

Перед запросом службы специальных возможностей NavXS показывает уведомление, в котором объясняется, как используется служба. Пользователь выбирает одну из двух кнопок: «Отклонить» или «Согласен». Только после нажатия «Согласен» NavXS открывает настройки специальных возможностей Android, где пользователь должен самостоятельно включить службу. «Отклонить» закрывает приложение, ничего не включая. Выход из уведомления любым другим способом не считается согласием. Службу можно в любой момент отключить в настройках специальных возможностей Android.

### 4.2 Для чего используется служба

Служба используется исключительно для того, чтобы:

- определять имя пакета приложения, которое в данный момент находится на переднем плане
- решать, нужно ли показывать оверлей для этого приложения
- отображать плавающие навигационные кнопки поверх выбранных приложений
- выполнять навигационные действия «Назад», «Домой» и «Недавние приложения», когда пользователь нажимает соответствующую кнопку

### 4.3 Чего служба не делает

Технически служба специальных возможностей имеет доступ к информации об окнах приложения на переднем плане. NavXS использует этот доступ только для определения имени пакета этого приложения. NavXS не считывает, не сохраняет и не передаёт введённый текст, пароли, содержимое сообщений или любое другое содержимое экрана. NavXS не выполняет никаких действий от имени пользователя, кроме указанных выше навигационных действий, и только когда пользователь нажимает кнопку.

Служба не используется в рекламных целях, для отслеживания или аналитики, а данные не продаются и не передаются третьим лицам.

## 5. Отсутствие передачи на внешние серверы

В настоящее время NavXS не передаёт выбранные приложения, имена пакетов приложений переднего плана или настройки оверлея на внешние серверы или в иные внешние сервисы.

Обработка происходит локально на устройстве.

## 6. Хранение данных

Настройки и выборы приложений, хранимые NavXS, сохраняются локально на устройстве.

Эти данные остаются на устройстве до тех пор, пока не будут изменены пользователем, удалены при очистке данных приложения или стёрты при удалении приложения.

Если пользователь выбирает снимок экрана в качестве фона редактора позиционирования, NavXS сохраняет только URI этого изображения вместе с предоставленным системой правом на чтение. Сам файл изображения не копируется, не сохраняется в каталоге приложения, не передаётся службе специальных возможностей и не отправляется. При сбросе фона сохранённый URI удаляется, а право на чтение снова освобождается.

## 7. Разрешения

NavXS в частности требует разрешения на доступ к специальным возможностям, явно включённого пользователем, чтобы приложение могло предоставлять функциональность оверлея.

Кроме того, используются только те доступы, которые технически необходимы для работы приложения.

## 8. Третьи стороны

В настоящее время NavXS не использует сторонние сервисы, аналитические инструменты или рекламу для обработки описанных выше данных.

## 9. Изменения настоящей политики конфиденциальности

Настоящая политика конфиденциальности может быть обновлена при необходимости для отражения изменений в приложении или требований законодательства.
