# NavXS 개인정보 처리방침

최종 업데이트: 2026년 9월 14일

## 1. 일반 정보

NavXS는 선택한 앱에 대해 고정 버튼이 있는 탐색 오버레이를 표시할 수 있는 Android 앱입니다.

이 앱의 개발자는 앱 기능에 기술적으로 필요한 범위 내에서만 개인 데이터를 수집, 저장 또는 처리합니다.

## 2. 기기에서의 로컬 처리

NavXS는 일반적으로 기기에서 로컬로 정보를 처리합니다.

이는 특히 다음을 포함합니다:

- 현재 포그라운드에서 실행 중인 앱의 패키지 이름
- 오버레이를 활성화해야 하는 앱 선택
- 위치, 색상, 크기, 투명도 및 테마와 같은 사용자 정의 오버레이 설정
- 접근성 서비스 활성화 여부 상태
- 사용자가 위치 조정 편집기의 배경으로 선택할 수 있는 이미지의 URI와 해당 이미지에 설정한 불투명도

## 3. 처리 목적

이 정보는 다음 목적으로만 처리됩니다:

- 현재 열려 있는 앱에 대해 오버레이를 표시해야 하는지 감지
- 오버레이 표시 또는 숨기기
- 구성된 탐색 작업 제공
- 사용자가 선택한 설정을 로컬에 저장 및 복원

## 4. 접근성 서비스

NavXS는 Android 접근성 서비스 API(AccessibilityService)를 사용합니다. NavXS는 장애가 있는 사용자를 위한 접근성 도구가 아니며, 이 서비스는 앱의 핵심 기능인 내비게이션 오버레이를 위해 필요합니다.

### 4.1 동의

접근성 서비스를 요청하기 전에 NavXS는 서비스 사용 방식을 설명하는 안내를 표시합니다. 사용자는 "거부"와 "동의" 두 개의 버튼 중에서 선택합니다. "동의"를 탭한 경우에만 NavXS가 Android 접근성 설정을 열며, 사용자는 그곳에서 직접 서비스를 활성화해야 합니다. "거부"를 탭하면 아무것도 활성화하지 않고 앱이 종료됩니다. 다른 방법으로 안내 화면을 벗어나는 것은 동의로 간주되지 않습니다. 서비스는 Android 접근성 설정에서 언제든지 비활성화할 수 있습니다.

### 4.2 서비스 사용 목적

이 서비스는 다음 목적으로만 사용됩니다.

- 현재 포그라운드에서 실행 중인 앱의 패키지 이름 감지
- 해당 앱에 오버레이를 표시할지 결정
- 선택한 앱 위에 플로팅 내비게이션 버튼 표시
- 사용자가 해당 버튼을 탭할 때 뒤로, 홈, 최근 앱 내비게이션 동작 실행

### 4.3 서비스가 하지 않는 일

접근성 서비스는 기술적으로 포그라운드 앱의 창 정보에 접근할 수 있습니다. NavXS는 이 접근 권한을 해당 앱의 패키지 이름을 확인하는 데에만 사용합니다. NavXS는 입력한 텍스트, 비밀번호, 메시지 내용 또는 기타 화면 콘텐츠를 읽거나 저장하거나 전송하지 않습니다. NavXS는 위에서 언급한 내비게이션 동작 외에는 사용자를 대신하여 어떤 동작도 수행하지 않으며, 이 동작도 사용자가 버튼을 탭한 경우에만 수행됩니다.

이 서비스는 광고, 추적 또는 분석 목적으로 사용되지 않으며, 데이터는 판매되거나 공유되지 않습니다.

## 5. 외부 서버로의 전송 없음

현재 NavXS는 선택된 앱, 포그라운드 앱의 패키지 이름 또는 오버레이 설정을 외부 서버나 기타 외부 서비스로 전송하지 않습니다.

처리는 기기에서 로컬로 이루어집니다.

## 6. 데이터 저장

NavXS가 저장하는 설정 및 앱 선택 사항은 기기에 로컬로 저장됩니다.

이 데이터는 사용자가 변경하거나, 앱 데이터 삭제로 제거하거나, 앱 제거로 삭제될 때까지 기기에 남아 있습니다.

사용자가 위치 조정 편집기의 배경으로 스크린샷을 선택하면 NavXS는 해당 이미지의 URI와 시스템이 부여한 읽기 권한만 저장합니다. 이미지 파일 자체는 복사되지 않고, 앱 디렉터리에 저장되지 않으며, 접근성 서비스로 전달되지 않고 전송되지도 않습니다. 배경을 초기화하면 저장된 URI가 삭제되고 읽기 권한도 다시 해제됩니다.

## 7. 권한

NavXS는 앱이 오버레이 기능을 제공할 수 있도록 사용자가 명시적으로 활성화한 접근성 권한을 특히 필요로 합니다.

또한 앱 운영에 기술적으로 필요한 액세스만 사용됩니다.

## 8. 제3자

현재 NavXS는 위에 설명된 데이터 처리를 위해 제3자 서비스, 분석 도구 또는 광고를 사용하지 않습니다.

## 9. 이 개인정보 처리방침의 변경

이 개인정보 처리방침은 앱의 변경 사항이나 법적 요구 사항을 반영하기 위해 필요한 경우 업데이트될 수 있습니다.
