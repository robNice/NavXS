# Політика конфіденційності NavXS

Останнє оновлення: 14 вересня 2026 р.

## 1. Загальні відомості

NavXS — це Android-застосунок, який може відображати навігаційний оверлей із фіксованими кнопками для вибраних застосунків.

Розробник цього застосунку збирає, зберігає або обробляє персональні дані лише в тій мірі, яка технічно необхідна для роботи застосунку.

## 2. Локальна обробка на пристрої

NavXS, як правило, обробляє інформацію локально на пристрої.

Це включає зокрема:

- назву пакету застосунку, який наразі знаходиться на передньому плані
- вибір застосунків, для яких має бути увімкнений оверлей
- налаштування оверлею, визначені користувачем, такі як позиції, кольори, розміри, прозорість і теми
- статус активації служби спеціальних можливостей
- URI зображення, яке користувач за бажанням вибирає як фон редактора позиціонування, разом із заданою для нього непрозорістю

## 3. Мета обробки

Ця інформація обробляється виключно для:

- визначення, чи потрібно показувати оверлей для поточного відкритого застосунку
- відображення або приховування оверлею
- виконання налаштованих навігаційних дій
- локального збереження та відновлення вибраних користувачем налаштувань

## 4. Служба спеціальних можливостей

NavXS використовує API служби спеціальних можливостей Android (AccessibilityService). NavXS не є інструментом спеціальних можливостей для людей з інвалідністю; служба потрібна для основної функції застосунку — навігаційного оверлею.

### 4.1 Згода

Перед запитом служби спеціальних можливостей NavXS показує повідомлення, яке пояснює, як використовується служба. Користувач обирає одну з двох кнопок: «Відхилити» або «Погоджуюсь». Лише після натискання «Погоджуюсь» NavXS відкриває налаштування спеціальних можливостей Android, де користувач має самостійно ввімкнути службу. «Відхилити» закриває застосунок, нічого не вмикаючи. Вихід із повідомлення будь-яким іншим способом не вважається згодою. Службу можна будь-коли вимкнути в налаштуваннях спеціальних можливостей Android.

### 4.2 Для чого використовується служба

Служба використовується виключно для того, щоб:

- визначати назву пакета застосунку, який зараз працює на передньому плані
- вирішувати, чи потрібно показувати оверлей для цього застосунку
- відображати плаваючі навігаційні кнопки поверх вибраних застосунків
- виконувати навігаційні дії «Назад», «Додому» та «Нещодавні застосунки», коли користувач натискає відповідну кнопку

### 4.3 Чого служба не робить

Технічно служба спеціальних можливостей має доступ до інформації про вікна застосунку на передньому плані. NavXS використовує цей доступ лише для визначення назви пакета цього застосунку. NavXS не зчитує, не зберігає і не передає введений текст, паролі, вміст повідомлень або будь-який інший вміст екрана. NavXS не виконує жодних дій від імені користувача, окрім зазначених вище навігаційних дій, і лише тоді, коли користувач натискає кнопку.

Служба не використовується для реклами, відстеження чи аналітики, а дані не продаються і не передаються третім особам.

## 5. Відсутність передачі на зовнішні сервери

Наразі NavXS не передає вибрані застосунки, назви пакетів застосунків переднього плану або налаштування оверлею на зовнішні сервери чи інші зовнішні служби.

Обробка відбувається локально на пристрої.

## 6. Зберігання даних

Налаштування та вибори застосунків, що зберігаються NavXS, зберігаються локально на пристрої.

Ці дані залишаються на пристрої до тих пір, поки не будуть змінені користувачем, видалені шляхом очищення даних застосунку або стерті при видаленні застосунку.

Якщо користувач вибирає знімок екрана як фон редактора позиціонування, NavXS зберігає лише URI цього зображення разом із наданим системою правом на читання. Сам файл зображення не копіюється, не зберігається в каталозі додатка, не передається службі спеціальних можливостей і не надсилається. Під час скидання фону збережений URI видаляється, а право на читання знову звільняється.

## 7. Дозволи

NavXS зокрема потребує дозволу на спеціальні можливості, явно увімкненого користувачем, щоб застосунок міг надавати функціональність оверлею.

Крім того, використовуються лише ті доступи, які технічно необхідні для роботи застосунку.

## 8. Треті сторони

Наразі NavXS не використовує сторонні служби, інструменти аналітики або рекламу для обробки описаних вище даних.

## 9. Зміни цієї політики конфіденційності

Ця політика конфіденційності може бути оновлена за необхідності для відображення змін у застосунку або законодавчих вимог.

## 10. Контакти

З питань конфіденційності ви можете звернутися до розробника.
